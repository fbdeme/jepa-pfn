## 6. Reading

- Long training keeps improving the value metric to the last pre-collapse snapshot and transfers to real data: the snapshot beats ds 40k on all three metrics and ties the E6 latinit 40k arm.
- The latent target collapses to a constant late in the run and takes the value head with it; the snapshot policy (upload every 20k) is what saved the model.
- Not established: whether the gain is the latent term's (needs the same structure with lambda_jepa 0 at matched steps) — ds has 6 blocks, the value path here has 10. Single seed.
- Parameter count is not the first lever against HistGB: the paper-prior base_ds at 20k is above this real-prior run at 180k, the old 34M ladder tied its base, and the largest gaps are multiclass wide-feature datasets (K_FEAT 64 cap, bar-head classification).
